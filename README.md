# Хаб основателя

Страница-посредник между шапкой Instagram @skl_leon и тремя направлениями.
Живёт на https://sklleon.github.io/leon/

## Зачем

Шапка профиля с 25.09.2026 называет три направления и зовёт «👇 Ссылки на все
проекты». До этой страницы ссылка вела в бот одного направления из трёх —
человек, пришедший за 1С или за техникой, попадал в воронку продвижения.

## Метка источника

Страница принимает `?s=<метка>` и передаёт её дальше: в Telegram через
`?start=`, на kvant1c.ru через `utm_campaign`. Без параметра — `hub_direct`.
Канон меток — `/Users/mrleo/Projects/SMM-лиды/scripts/метки.py`, префикс `hub_`
заведён там же 25.09.2026.

Адрес для шапки Instagram: `https://sklleon.github.io/leon/?s=ig_bio`

## Чего на странице нет и почему

- **Фото.** Правило 8 глобальных правил закрывает графику в git; фото ставится
  только по прямой просьбе владельца (`git add -f`). Пока монограмма «ЛС».
- **Телефон и почта.** Не записаны ни в одном реестре — прочерк честнее
  выдуманного (правило 7). Каждая кнопка ведёт туда, где можно написать.
